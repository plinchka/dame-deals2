# Скидки на игры

Учебное приложение (Vite, React, TypeScript и API). Показывает актуальные скидки на PC-игры из разных магазинов: поиск по названию, выбор магазина, сортировка(по убыванию, по возрастанию, по положительным отзывам в стим) и кнопка обновления.

## Ссылки

- API: [CheapShark](https://apidocs.cheapshark.com/) — `https://www.cheapshark.com/api/1.0` (разделы `/deals` и `/stores`), ключ не нужен

## Что умеет приложение

- загружает предложения через `fetch`;
- поиск по названию игры (с задержкой 400 мс, чтобы не слать запрос на каждую букву);
- фильтр по магазину, сортировка и кнопка «Обновить»;
- кнопка «Показать ещё» подгружает следующие страницы (по 24 предложения), не стирая уже показанные;
- состояния: «Загрузка…», список карточек, «Ничего не найдено», ошибка с кнопкой «Повторить»;
- проверка `response.ok`, отмена устаревших запросов через `AbortController`;
- ссылка на покупку открывает страницу предложения в магазине.

## Структура проекта

```
src/
  main.tsx            точка входа
  App.tsx             состояние фильтров и сборка страницы
  api.ts              запросы к CheapShark
  types.ts            типы Deal, Store, Filters, SortKey
  hooks/              useDeals, useStores, useDebouncedValue
  components/         Button, Controls, DealList, DealCard, States
  style.css           стили (имена классов по БЭМ)
```

## Запуск

```bash
npm install
npm run dev      # режим разработки, http://localhost:5173
npm run build    # сборка в папку dist
npm run preview  # посмотреть собранную версию локально
```
